# evolution-theory-web-research
# Web Platform for Evolutionary Theory Research

## 📝 Project Overview
This project combines scientific research and web development, focusing on the Theory of Evolution. It was successfully developed and evaluated as an academic project at the **Universidade de Aveiro**. 

The repository includes the full source code of the web platform and the official comprehensive research report (Relatório) detailing our findings.

## Repository Structure
Basándose en la estructura actual del repositorio:
* `/projeto`: Web application source code (HTML and CSS layout).
* `/report-template`: The official academic research paper source and documents written in LaTeX.

## Technologies Used
* Frontend: HTML5, CSS3, Bootstrap (for responsive design)
* Documentation & Scientific LaTeX

## Research Abstract
The attached report covers an in-depth investigation into the historical and modern mechanisms of evolutionary theory. The web platform was designed to dynamically present this data, making scientific research accessible through an intuitive user interface utilizing modern Bootstrap frameworks.

*Note: The platform was originally deployed on the Universidade de Aveiro's internal servers for evaluation purposes. The live link is hosted on the university's private intranet and may have restricted external access.*
